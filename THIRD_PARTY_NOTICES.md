# Mentions tierces

Ce prototype de candidature est indépendant. MénageSimple, Stonks Holding AG, GitHub et AWS sont cités pour désigner les entreprises ou services concernés ; aucun partenariat, produit officiel ou soutien n’est revendiqué.

Les courts extraits de menagesimple.com restent des textes de leur source et ne sont pas placés sous la licence MIT du code. Les liens, dates et périmètres sont conservés dans sources.json. Les captures représentent le prototype réel ; aucune image de stock ni donnée client n’est incluse.

L’application utilise uniquement la bibliothèque standard de Python à l’exécution. Python et les outils facultatifs de test / enregistrement restent soumis à leurs propres licences ; ils ne sont pas redistribués dans ce dépôt.
